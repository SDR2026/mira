# Mira workflow flow diagrams

These diagrams correspond to DR-5 in the Scope of Work. Each Mermaid source (`.mmd`) is editable in GitHub; the matching PNG is included for direct viewing and in the design/evaluation evidence supplement.

| Flow | Purpose |
|---|---|
| W-1 | Request intake, routing and insufficient-input branch |
| W-2 | Grounded project plan |
| W-3 | Categorized risk assessment |
| W-4 | Weekly status report, counts and health |
| W-5 | Blocked, overdue and due-soon tracking |
| W-6 | Sprint-isolated stakeholder update |
| W-7 | Evaluate, fix and retest loop |
